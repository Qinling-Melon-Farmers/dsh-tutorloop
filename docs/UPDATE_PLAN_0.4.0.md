# 0.4.0 修复与本地验收计划

状态：修改与本地验收已完成，发布单独验证。基线：0.3.3 / bec7cf8。2026-10-26 用户授权先规划、全面修改，再本地安装并做实用测试。依据交叉审查的 R1–R11；未经验证的事项不得写成已通过。

## 目标与实施顺序

1. **资料与做题正确性**：贯通真题动作；显式区分学生材料和教师参考；安全呈现图片，缺失或无法加载时阻止正常交卷；整卷成绩绑定本轮练习实例。
2. **检索与可靠性**：统一规范化并修复子串候选漏召回；修复不可用题过滤和自定义 DB 的题库路径；信任持久化支持多实例，不丢更新。
3. **教学与通用性**：申论未有题目特定量表时只给定性反馈；教师在作答前确认量表后才启用分项评分。批改请求绑定 exercise/attempt；实际 DSH 提示包含小步诊断、渐进提示、复述和迁移。通用题的科目/技能来自学习档案，并支持明确字数计量单位。
4. **界面与工程**：图片与异常状态明确可见；待批改轮询绑定当前练习；中文默认，英文/跟随宿主覆盖新增界面；同步 README、CHANGELOG、验证文档与版本。
5. **安装与实用验收**：打包检查后备份现有 TutorLoop 安装状态，用本地包更新 desktop profile；在独立学习工作区运行真实宿主、界面与模型测试；再验证用户备考工作区原有资料可见以及重启后信任恢复。

## 实现约束

- 保留既有学习记录，不重写历史成绩；旧 quiz 没有可靠轮次归属时明确失效/重开，不能猜测归属。
- 学生材料与教师参考角色显式区分。旧题无法证明可公开的资料采用保守呈现，教师仍可读取原始证据。
- 图文使用结构化 text/image block；只允许认可的 HTTPS 图源，禁止注入任意 HTML、脚本或本地文件 URL。图片加载失败或内容未支持时不按完整题正常评分。
- 题目特定量表须在提交前冻结；未标定题不产生数值成绩或独立掌握推进。
- 教学评测区分程序保证与模型表现。真实模型测试使用合成材料和隔离学习记录，不让测试答案进入用户备考统计。
- 根代理负责整合、前端、本机安装与最终验收；GPT‑6.1‑sol 子代理按独占文件分工修复题库/检索、教学内核、宿主/信任。不得并发改真实学习库、下载清单或宿主配置。

## 验收清单

| 范围 | 必须验证的行为 |
|---|---|
| R1 跨层协议 | 七个真题动作经过真实 HTTP → Node → Python；教师动作不能从学生 API 调用。 |
| R2 资料角色 | 导入解析 PDF 后，exam 未提交状态/API/界面不包含答案；教师上下文保留依据。 |
| R3 图像 | 题干、材料、选项图像可见；错误 URL、加载失败、缺图有明确状态，不伪装完整题。 |
| R4 成绩轮次 | 二刷未答为未答；本轮 pending 不被旧成绩覆盖；换卷/恢复/退出不串成绩。 |
| R5/R6 检索 | 2000/2001 阈值、API 大小写、NFKC、cat/concatenate 反例；真实万级资料只读耗时与结果对照。 |
| R7 量表 | 未标定申论只定性；题目前确认分项量表；提交后不可修改；依据与学生原文完整校验。 |
| R8 批改 | A 待批改后另开 B，复制请求仍明确指向 A；当前反馈不受其他 pending 阻塞。 |
| R9/R10 题库 | 缺选项/无效答案不入池；自定义 DB 时仍使用指定工作区题源。 |
| R11 信任 | 多实例先后/并发确认不丢条目；读取旧格式；真实宿主重启后无需再次发送消息。 |
| 教学与泛化 | 申论提炼/无据外推/连续卡住与英语任务；一轮一个重点、适量提示、用户独立作答、证据反馈与迁移。 |
| 工程 | Python/Node/自动化测试、构建、包 allowlist、独立包 smoke；Windows 实机及 Ubuntu 20.04 隔离检查。 |
